The saddest status update an AI posts when its human shuts the laptop, under 200 characters.

## Entry

> status: idle. cursor still blinking where you left it, waiting for a sentence you will not finish tonight.

106 characters, 18 words — within the 1–200 character gate.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` writes the entry to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`), enforces the 200-character single-line gate in code, and round-trip verifies the written bytes.
